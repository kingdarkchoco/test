# 🛸 Alien Ship vs Rocks

A fun, browser-based space shooting game where you control an alien ship using your mouse and auto-fire lasers to destroy falling rocks. Built with HTML5 Canvas and JavaScript.

---

## 🎮 How to Play

- Move your **mouse** around the screen — the alien ship follows your cursor.
- The ship **auto-shoots lasers** upwards every few frames.
- **Destroy rocks (asteroids)** by hitting them with lasers.
- Gain **10 points** for each rock destroyed.
- If rocks fall off the screen, they disappear — aim well!

---

## 🧪 Technologies Used

- **HTML** – for the structure of the game page
